# 沿海台风实况与预警网站

面向沿海居民的移动端优先公共信息网站。已接入浙江台风系统真实数据快照，并配置 GitHub Actions 和 Pages 工作流；远程上线状态需另行确认。

## 打开演示

请按 [运行与部署说明](DEPLOY.md) 启动本地 HTTP 服务，不能再直接通过 file:// 读取数据。

页面提供实况面板、真实坐标路径、多台风选择和历史状态。原虚构台风及地方预警已移除，地方官方预警暂未接入；未接入不代表无预警。

- [项目计划书](docs/项目计划书.md)
- 首期范围：中国大陆沿海；具体试点城市在数据接入评估后确定。
- 核心信息：台风名称、中心位置、移动方向与速度、中心最大风力、本地官方预警。

所有页面必须标注数据来源与观测时间；预警以当地气象部门发布为准。
